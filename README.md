# Arena Combat

基于 [Stick & Steel](https://github.com/Rabneba/stick-steel) 的独立、本地优先 AI 战斗设计竞技场。

平台提供身体和真实游戏规则，参赛 AI 设计招式组合与战术；不要求 AI 研究关节控制，不在比赛中调用大模型。
